# F - Entry points: honest retrospective entry into the 10-stage paper workflow
Scope: what methodology and integrity literature says about admitting half-finished or finished papers without claiming that early gates (plan freeze, pre-question scan, confirmatory status) were passed. Date of search 2026-10-04.
Method: 12 searches (9 Consensus, 3 web) and 10 fetches. All 10 fetches were blocked by the egress proxy (icmje.org, cos.io, PCI, PMC, BMJ, OSF/LNU), so no full page was read; claims rest on abstracts or search snippets.
Grades: A peer-reviewed/official; B systematic independent (preprint); C anecdote/blog. UNVERIFIED = detail beyond what the abstract/snippet showed, or page not read. Dates are publication years.

## Entry scenarios and what honesty requires
Stages: S1 inventory, S2 pre-question scan, S3 question, S4 plan freeze, S5 analysis, S6 analysis-to-question map, S7 Methods/Results, S8 citation ledger, S9 verification gate, S10 Intro/Discussion/critique/audit. Columns 2-4 are my synthesis; no source prescribes this stage mapping.
| Entry | Stages passable normally | Gates only passable as retrospective audit | Must be disclosed in the paper | Evidence |
|---|---|---|---|---|
| (a) Data collected, no analysis | S1 (add a data-access log: who has seen which variables), S3, S4 (valid freeze if no outcome-level looks yet), S5-S10 | S2 (question already shaped by design and data in hand; log as post-design); S4 covers analysis only, not design or sample size | Dates of collection and of freeze; plan postdates data but predates analysis; any prior looks at data; when inclusion/exclusion rules were fixed | #4, #7-#12 |
| (b) Analysis done, nothing written | S1, S7 (from as-run scripts), S8, S9, S10 critique | S2 (post-results scan, flag HARKing-by-literature risk), S3 (question set after results = post hoc), S4 (cannot be passed; substitute dated as-run analysis log), S5 (nothing is confirmatory), S6 (built backwards; label every row post hoc) | No plan was frozen; all analyses exploratory; every analysis run, not only those reported; order of analyses; how the question was chosen; Tharking subsection; robustness results | #1-#2, #5-#6, #13-#19, #31 |
| (c) Half-written draft | S8 and S9 (re-extract the draft's citations from full text), S10 | Everything in (b), plus re-audit of Introduction: any hypothesis first appearing in a draft dated after the first result is labelled post hoc; S6 built from draft claims back to analyses, orphan claims flagged | As (b), plus which Introduction hypotheses were written or changed after results were known (dated drafts/version history as evidence) | #1-#2, #23, #27-#28 |
| (d) Finished manuscript before submission | S9 (every in-text claim against its source, Introduction and Discussion included), S10 submission audit, S8 for sources never read in full | S1-S7 become provenance reconstruction from dated artefacts (proposal, commits, emails); each result tagged documented-prior-plan or post hoc | Provenance statement near Methods; extended disclosure statement; confirmatory/exploratory label per result; deviations from any earlier written plan; robustness section; an explicit "not preregistered" statement, never "registered" implying equivalence | #4, #13, #16-#19, #23-#25, #27-#30, #37 |
| (e) Under revision after review | S9 re-run on new or changed citations plus retraction check, S10 critique, S5 only for newly requested analyses | Everything before first submission; archive the as-submitted version as the time-stamped baseline so revisions are a diff | Reviewer-requested analyses labelled as such; any change in hypotheses, analyses or conclusions between versions (deviation-log style); response letter consistent with labels | #23, #24, #29, #33 |

## Robustness options when the plan was never frozen
- Multiverse or specification curve over the defensible set (#17-#19): write down the rule for the specification set before running it and justify which choices are arbitrary (Type E/N/U); report as descriptive unless joint inference is done (#20 shows it rarely is). It exposes fragility; it does not restore confirmatory status.
- Independent second analyst given the question and raw data, not the original code (#21, #22): ecology results varied in size and sign across analysts; no guideline for reporting a single re-analysis was found.
- Hold-out or new data (#10, #11, #12, #35): a hold-out is valid only if never explored (check the access log); a new season, site or replicate is the strongest route; the Explore-and-Confirm pattern suits future datasets.
- Sensitivity-analysis reporting (#36, #26): list decisions and assumptions varied and the effect on the main estimate (evidence is from meta-analysis; transfer to field data is inference).
- Full disclosure of what was run (#1, #4, #31): all analyses, exploratory labels, Tharking subsection, extended disclosure statement.
- Calibrate claim language: post hoc results are preliminary (#5); non-preregistered literatures show more significant results (#37).

## Gaps
- No source accepts registration after analysis as equivalent to preregistration. Clinical trials tolerate late registration only with disclosure (#13-#16); the secondary-data templates register before analysis (#9-#11). No ecology position on late registration found.
- Not reachable (all fetches blocked): ICMJE, PCI Ecology and PCI RR guides, TOP 2025, OSF Transparent Changes, Van den Akker template items, E&E RR policy. McIntosh 2017 may be withdrawn or reissued; check before citing.
- No integrity body (COPE, ICMJE, ORI) guidance on retrospective manuscript citation audits retrieved (COPE not searched); evidence is meta-research on quotation errors and one verification-sheet model (#28).
- No ecology/evolution journal found with a Stage-2-only or "exploratory report" article type; Cortex (neuroscience) and DCN (secondary-data RRs) are the nearest. Whether BMC Ecology and Evolution or E&E accept data-driven work labelled exploratory was not established (ordinary articles presumably do).
- Most methods evidence is from psychology and medicine; ecology-specific support is #21, #31, #32. Tharking (#1) is an editorial; Rubin (#2) argues HARKing costs are overstated. Wagenmakers 2012 and the 21-word text were not read directly.

## Implications for the workflow structure
- Give each stage a provenance status: PASSED-PROSPECTIVE, PASSED-RETRO-AUDIT, or NOT-PASSED (as-run record). S4 can never be PASSED-RETRO (#13, #16).
- Derive the S5 label from provenance: confirmatory only with a dated plan and an access log showing no prior look at outcomes (#9-#11); all else exploratory, with a Tharking subsection and the extended disclosure statement (#1, #4).
- Add a robustness bundle as the retrospective substitute (multiverse/spec curve, second analyst, hold-out or new data), with its own rule written before it is run (#17-#22).
- Run S8-S9 in full at every entry point: they do not depend on results; base rates (~17% quotation error, 89% unaware of retractions, fabricated LLM references) justify a full-text claim-support check using a verification sheet (#27-#30).
- Add a changes log usable at any stage, including revision, plus a TOP-style disclosure checklist tied to the paper (#4, #23-#25).
