# Demo dataset (synthetic) — for the first-use pilot only
`wetland_demo.csv`: 12 wetlands (W01–W06 restored in 2019; W07–W12 reference), sampled spring and autumn in 2022–2024 (72 rows). Variables: hydroperiod_days, water_depth_cm, conductivity_uScm, emergent_cover_pct, macroinvert_richness (family level), odonata_species, amphibian_species, sampling_effort_min. Some conductivity values are missing in 2022; W09 was not sampled in autumn 2023. Generated with a fixed random seed; it contains no real field data. Treat it as "data collected, no analysis yet" (entry mode a-data-only).
